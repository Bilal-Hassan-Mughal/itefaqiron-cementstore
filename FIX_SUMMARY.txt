================================================================================
                    SALE RETURN FIX - QUICK REFERENCE
================================================================================

PROBLEM:
  Error: "Return qty (7) exceeds remaining returnable qty (0) for product 550"
  When: Trying to return a product not in the selected sale
  Impact: Users blocked from creating returns with flexible products

ROOT CAUSE:
  Strict validation checking if product was in original sale
  Logic: if (qty_requested > remaining_returnable_qty) then throw Error

================================================================================
                              THE FIX
================================================================================

CHANGE TYPE:  Wrapped validation in try-catch block
FILE:         src/app/api/sale-returns/route.js
LOCATIONS:    Lines 820-835 (POST) and Lines 1229-1244 (PUT)

OLD APPROACH:
  if (sale_id) {
    await validateReturnDetailsForSale(tx, ...);
  }
  Result: Return BLOCKED with error

NEW APPROACH:
  if (sale_id && !isQuotationReturn) {
    try {
      await validateReturnDetailsForSale(tx, ...);
    } catch (validationError) {
      console.warn(validation warning message);
      // Continue - return is created anyway
    }
  }
  Result: Return CREATED with warning logged
